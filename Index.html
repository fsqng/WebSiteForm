⚙️ Настройка — сделайте один раз перед публикацией:
  1. Создайте Google Таблицу на sheets.google.com, скопируйте её ID из адресной строки
  2. Зайдите на script.google.com, создайте новый проект, вставьте код из файла google-script.js
  3. Вставьте ID таблицы в скрипт вместо ВАШ_ID_ТАБЛИЦЫ
  4. Нажмите Развернуть → Новое развёртывание → Веб-приложение → Доступ: Все
  5. Скопируйте URL скрипта и вставьте в этот файл вместо https://script.google.com/home/projects/1Ou4FmErRUWAzHZEUev7aOzwgJlkrptwO-lujR2UH4qZm-dybAgCnfteb/edit
  6. Выложите файлы на GitHub Pages
